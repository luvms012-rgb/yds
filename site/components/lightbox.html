사용법

아래 구조를 복사해 사용합니다. 대괄호 [ ]로 묶인 부분은 크기나 설명 글처럼 생략할 수 있는 선택 항목입니다. 사용할 때는 대괄호만 지우고, 사용하지 않을 때는 대괄호를 포함해 해당 부분을 모두 지우세요.

구조

2 / 4
구성 요소설명
Bar ds-lightbox__bar값만큼 높아지는 막대입니다.
Count ds-lightbox__count개수나 글자 수를 표시합니다.
Close ds-lightbox__close닫기 버튼입니다.
Slide ds-lightbox__slide사진 한 장과 설명을 담은 영역입니다.
Img ds-lightbox__img크게 표시하는 사진입니다.
Caption ds-lightbox__caption사진 설명입니다.
Nav ds-lightbox__nav이전 달, 다음 달로 넘기는 버튼입니다.

속성

Figma 속성 이름을 그대로 data-* 속성으로 사용합니다.

그 밖에: data-ds-open + data-ds-index, 좌우 화살표 키, 사진 개수 표시

동작

ybm-ds.js를 불러오면 자동으로 동작합니다.

  • Dialog 와 같이 열고 닫기, data-ds-index 로 시작 사진, 이전/다음 버튼과 좌우 화살표 키로 넘기기

사용 지침

구분내용
Do사진을 크게 볼 필요가 있을 때만 사용합니다. 작은 이미지를 확대하는 데는 사용하지 않습니다.
Do모든 사진에 alt를 넣습니다.
Do전체 사진 수와 현재 위치를 표시합니다.
Don'tLightbox 안에서 다른 창을 열지 않습니다.

규격

CSS 변수

서비스에서 모양을 바꿀 때는 이 변수만 덮어씁니다.

변수기본값
--ds-lightbox-bgvar(--ds-color-palette-static-black-alpha-900)
--ds-lightbox-fgvar(--ds-color-palette-static-white)
--ds-lightbox-button-bgvar(--ds-color-palette-static-white-alpha-200)

크기와 여백

여는 버튼: data-ds-open="lb" [data-ds-index="2"](몇 번째 사진부터) / 버튼이나 좌우 화살표 키로 넘기고, Esc나 빈 곳을 누르면 닫힙니다
바탕은 항상 어둡습니다(사진이 잘 보이도록 라이트와 다크 모드가 같습니다)
