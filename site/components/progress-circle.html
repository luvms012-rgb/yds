Progress Circle

작업이 진행 중임을 회전하는 원으로 표시하는 컴포넌트입니다.

Figma코드
새 창으로 열기
전체 목차 yds.txt
불러오는 중이에요

사용법

아래 구조를 복사해 사용합니다. 대괄호 [ ]로 묶인 부분은 크기나 설명 글처럼 생략할 수 있는 선택 항목입니다. 사용할 때는 대괄호만 지우고, 사용하지 않을 때는 대괄호를 포함해 해당 부분을 모두 지우세요.

구조

구성 요소설명
Track ds-progress-circle__track막대의 바탕입니다.
Range ds-progress-circle__range진행률을 표시하는 호입니다.

속성

Figma 속성 이름을 그대로 data-* 속성으로 사용합니다.

속성값
toneneutral brand staticWhite
켜고 끄는 속성size indeterminate

사용 지침

구분내용
Do로딩은 Progress Circle의 indeterminate로 표시합니다.
DoSpinner 컴포넌트는 따로 없습니다.
DostaticWhite는 어두운 배경이나 사진 위에서만 사용합니다.
Dodeterminate는 진행률을 실제로 알 수 있을 때만 사용합니다. 모를 때는 indeterminate를 사용합니다.

예시

완료 시점을 모를 때는 indeterminate

목록 끝에서 다음 내용을 불러올 때처럼 언제 끝날지 모르면 data-indeterminate를 사용합니다. 알 수 없는 진행률을 임의로 채우면 멈춘 것처럼 보입니다.

  • 겨울 방학 특강 안내 12월 2일
  • 시스템 점검으로 잠시 쉬어요 11월 28일

진행률을 알 때만 determinate

파일을 내려받을 때처럼 진행 정도를 알 수 있으면 determinate를 사용합니다. 옆에 "72%"처럼 값을 함께 표시해 남은 양을 알려 줍니다.

  • 3주차 강의 자료.pdf 24MB 중 17MB, 72%
  • 2주차 강의 자료.pdf 18MB, 내려받았어요

규격

CSS 변수

서비스에서 모양을 바꿀 때는 이 변수만 덮어씁니다.

변수기본값
--ds-progress-value40

크기와 여백

tone: neutral(기본) / brand / staticWhite   size: 24(기본) / 40 / 56   indeterminate: 켜기
  indeterminate: data-indeterminate (회전하는 25% 호, 예전 data-type="indeterminate" 도 읽음)
Figma: 두께 24→3 / 40→5 / 56→7 / 둥근 끝 / 12시 시작
  트랙 bg/neutral-weak-alpha(2026-11-11 모든 색 같음) / neutral 호 palette/gray-500 / brand 호 bg/brand-solid
  staticWhite palette/static-white-alpha-300 + palette/static-white (팔레트를 직접 참조하는 것은 의도된 예외)
