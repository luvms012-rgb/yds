Mega Menu

상단 메뉴 아래로 펼쳐져 하위 메뉴 묶음을 한 번에 표시하는 패널입니다.

Figma코드
새 창으로 열기
전체 목차 yds.txt

영어

  • 토익
  • 토익 스피킹
  • 회화

제2외국어

  • 중국어
  • 일본어
  • 스페인어

자격증

  • 컴퓨터 활용
  • 한국사
  • 공무원

사용법

아래 구조를 복사해 사용합니다. 대괄호 [ ]로 묶인 부분은 크기나 설명 글처럼 생략할 수 있는 선택 항목입니다. 사용할 때는 대괄호만 지우고, 사용하지 않을 때는 대괄호를 포함해 해당 부분을 모두 지우세요.

이번 달 추천

토익 실전 모의고사

구성 요소설명
Item ds-topnav__item목록의 항목 하나입니다.
Inner ds-megamenu__inner내용을 가운데에 정해진 폭으로 담는 영역입니다.
Group ds-megamenu__group관련 항목을 묶는 영역입니다.
Title ds-megamenu__title제목입니다.
List ds-megamenu__list항목 목록입니다.
Link ds-megamenu__link자세히 보기 같은 이동 링크입니다.
Aside ds-megamenu__aside추천 내용을 배치하는 옆 영역입니다.

속성

Figma 속성 이름을 그대로 data-* 속성으로 사용합니다.

그 밖에: 트리거 data-ds-megamenu + aria-expanded, 묶음 4개까지, aside(선택)

동작

ybm-ds.js를 불러오면 자동으로 동작합니다.

  • data-ds-megamenu 트리거로 열고 닫기, Esc 와 바깥 누름으로 닫기

사용 지침

구분내용
Do하위 메뉴가 많은 PC 화면에서만 사용합니다. 모바일은 Menu Sheet를 사용합니다.
Do묶음은 4개까지 두고 묶음 제목을 붙입니다.
Do마우스를 올리는 것만으로는 열지 않고, 눌렀을 때 엽니다.
Don't패널 안에 입력 필드나 긴 설명을 넣지 않습니다.

규격

CSS 변수

서비스에서 모양을 바꿀 때는 이 변수만 덮어씁니다.

변수기본값
--ds-megamenu-width1200px
