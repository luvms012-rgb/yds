Segmented Text Input

주민등록번호, 카드번호처럼 일부를 가려야 하는 값을 구간마다 나눠 받는 입력 칸입니다.

새 창으로 열기
전체 목차 yds.txt
---

사용법

아래 구조를 복사해 사용합니다. 대괄호 [ ]로 묶인 부분은 크기나 설명 글처럼 생략할 수 있는 선택 항목입니다. 사용할 때는 대괄호만 지우고, 사용하지 않을 때는 대괄호를 포함해 해당 부분을 모두 지우세요.

구성 요소설명
Segment ds-segmentinput__segment자리 수만큼 따로 입력하는 구간입니다.
Separator ds-segmentinput__separator구간 사이를 나누는 기호입니다.
Dots ds-segmentinput__dots입력받지 않는 자리를 표시하는 점입니다.
Suffix ds-segmentinput__suffix카드사 로고를 두는 자리입니다.

속성

Figma 속성 이름을 그대로 data-* 속성으로 사용합니다.

속성값
sizelarge medium medium 은 PC 전용
켜고 끄는 속성disabled readonly

그 밖에: 가린 구간 data-masked, aria-invalid, 구간마다 maxlength

동작

ybm-ds.js를 불러오면 자동으로 동작합니다.

  • 자리 수를 채우면 다음 구간, 빈 구간에서 Backspace 는 앞 구간 마지막 글자 지우기, 끝과 처음에서 좌우 화살표로 옆 구간, 붙여 넣으면 구분자를 빼고 차례로 채우되 가린 구간 앞에서 멈춤, 한글 조합 중에는 옮기지 않음

사용 지침

구분내용
Do주민등록번호, 카드번호처럼 일부 자리를 가려야 하는 값에만 사용합니다.
Do형식만 정해진 값(전화번호, 이메일, 유효기간)은 Text Field 하나로 받습니다.
Do구간마다 maxlength와 자리를 알리는 aria-label을 넣고, 숫자만 받는 구간에는 inputmode="numeric"을 넣습니다.
Do받지 않는 자리는 점(dots)으로 표시해 전체 자리 수를 알립니다.
Do틀린 구간에 aria-invalid="true"를 붙이고, 입력 필드 아래 안내 글로 고치는 방법을 알립니다.
Don't인증번호를 한 칸에 한 글자씩 받을 때는 사용하지 않습니다. Code Input을 사용합니다.

Text Field와 비교

일부 자리를 가려야 하는 값에만 Segmented Text Input을 사용합니다. 전화번호, 이메일, 유효기간처럼 형식만 정해진 값은 Text Field 하나로 받고, 인증번호를 한 칸에 한 글자씩 받을 때는 Code Input을 사용합니다.

항목Segmented Text InputText Field
사용 맥락주민등록번호, 카드번호전화번호, 이메일, 유효기간, 그 밖의 한 줄 값
입력 칸구간마다 입력 칸 하나입력 칸 하나
가리기가린 구간은 점으로 표시, 받지 않는 자리도 점으로 표시가리지 않음
구간 이동자리 수를 채우면 다음 구간으로 이동없음
붙여 넣기구분자를 빼고 차례로 채우되 가린 구간 앞에서 멈춤그대로 입력

예시

주민등록번호

앞 6자리와 뒷자리 첫 자리만 입력받고, 받지 않는 나머지 6자리는 점으로 표시합니다. 앞 6자리를 채우면 다음 구간으로 이동합니다.

규격

CSS 변수

서비스에서 모양을 바꿀 때는 이 변수만 덮어씁니다.

변수기본값
--ds-segmentinput-gapvar(--ds-space-x1_5)
--ds-segmentinput-dot7px
--ds-segmentinput-dot-gapvar(--ds-space-x1)
--ds-segmentinput-suffix-width30px
--ds-segmentinput-suffix-height20px
--ds-segmentinput-chars4
--ds-segmentinput-filled0
--ds-segmentinput-slotcalc(var(--ds-segmentinput-dot) + var(--ds-segmentinput-dot-gap))

크기와 여백

size: large(기본) 높이 52, shape/lg, t05 / medium(PC 전용) 높이 40, shape/sm, t04
입력 필드는 Text Field outline과 같습니다(aria-invalid, disabled, readonly) / 구간 너비는 maxlength 자리 수만큼, 구간과 구분자 사이 x1_5
data-masked: 입력한 글자를 점으로 표시합니다 / dots: 받지 않는 자리를 지름 7 점으로 표시합니다, 점 사이 x1
suffix 30x20, shape/2xs, bg/neutral-weak-alpha(카드사 로고 자리), 아이콘을 넣으면 28x28 정사각형(아이콘 16) / 라벨, 도움말, 오류는 Field Label(.ds-field)로 감쌉니다
형식만 정해진 값(전화번호, 이메일, 유효기간)은 Text Field, 인증번호를 한 칸에 한 글자씩 받을 때는 Code Input을 사용합니다
ybm-ds.js: 자리 수를 채우면 다음 구간으로 이동하고, 빈 구간에서 Backspace는 앞 구간의 마지막 글자를 지웁니다
