Get Started

YDS는 다양한 서비스를 일관된 경험으로 만들기 위한 디자인 시스템입니다.

Figma코드
새 창으로 열기
전체 목차 yds.txt

구조

  1. YDS모든 서비스가 함께 쓰는 컴포넌트, 토큰, 규칙입니다.
  2. 브랜드색, 모서리, 글꼴처럼 브랜드마다 달라지는 값만 담은 파일입니다.
  3. 서비스YDS와 브랜드 파일을 불러와 실제 화면을 만듭니다.

AI와 함께 시작하기

아래 틀을 참고해 하고 싶은 일을 자유롭게 적어 AI 도구에 붙여 넣으세요.

Figma로 시작하기

  1. 라이브러리 켜기Figma의 Assets 패널에서 YDS 라이브러리를 켭니다.
  2. 화면 그리기컴포넌트와 색, 간격, 글자 등을 직접 넣지 않고 YDS에 있는 값에서 선택해서 사용합니다.

Assets에 YDS 라이브러리가 보이지 않으면 의견 보내기로 팀 초대를 요청하세요.

개발 시작하기

파일

파일무엇인가요언제 쓰나요
yds.txtYDS 안내서가장 기본이고 중요한 파일입니다. 잘 모르면 AI 요청 글에 이 주소를 꼭 넣으세요.
Figma 라이브러리YDS 컴포넌트와 변수가 담긴 Figma 파일Figma로 화면을 그릴 때 켭니다. 디자이너는 이것 하나면 됩니다.
yds-full.txt컴포넌트 사용법과 규칙을 모은 파일 하나AI가 주소를 열지 못할 때 yds.txt 대신 이 파일을 첨부합니다. 내용은 더 자세합니다.
CLAUDE.mdyds.mdcAGENTS.md코딩 도구용 YDS 규칙 파일코딩 도구로 개발할 때 프로젝트 맨 위 폴더에 둡니다. 한 번 두면 요청 글마다 안내서 주소를 넣지 않아도 됩니다.
yds-check.mjsYDS 규칙 검사 스크립트화면을 다 만든 뒤 한 번 돌립니다. YDS에 없는 색이나 클래스를 썼는지 찾아 줍니다.
brands등록된 브랜드 파일내 서비스에 브랜드가 있는지, 색과 모서리 값이 무엇인지 볼 때 엽니다. 없으면 AI 요청 글의 [브랜드 만들기]로 시작합니다.
