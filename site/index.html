Get Started

YDS는 다양한 서비스를 일관된 경험으로 만들기 위한 디자인 시스템입니다.

Figma코드
새 창으로 열기
전체 목차 yds.txt
기획, 운영AI로 요청하기코드를 몰라도 요청 글 하나로 시작합니다.디자이너Figma로 그리기YDS 라이브러리를 켜고 화면을 그립니다.퍼블리싱, 개발사이트에 설치하기<head>에 두 줄만 넣으면 됩니다.

구조링크 복사

서비스 화면은 YDS에 브랜드 값을 더해 만들어집니다.

  1. YDS모든 서비스가 함께 쓰는 컴포넌트, 토큰, 규칙입니다.
  2. 브랜드색, 모서리, 글꼴처럼 브랜드마다 달라지는 값만 담은 파일입니다.
  3. 서비스YDS와 브랜드 파일을 불러와 실제 화면을 만듭니다.

AI와 함께 시작하기링크 복사

Claude, ChatGPT, Cursor 같은 AI 도구에 아래 글을 붙여 넣으면 YDS 규칙대로 화면을 만듭니다. 어떤 서비스의 어떤 화면인지, 들어갈 내용 순서, 그대로 둘 부분을 적을수록 정확해집니다.

주소를 열 수 없는 도구에는 yds-full.txt 파일을 대화창에 첨부합니다. 안내서 전체가 한 파일에 들어 있습니다.

Figma로 시작하기링크 복사

Figma에서 작업을 시작할 때는 YDS 라이브러리를 사용합니다.

  1. 라이브러리 켜기Figma의 Assets 패널에서 YDS 라이브러리를 켭니다.
  2. 화면 그리기컴포넌트와 색, 간격, 글자 등을 직접 넣지 않고 YDS에 있는 값에서 선택해서 사용합니다.
구분내용
Do색, 간격, 글자는 YDS 변수에서 선택합니다. 예: bg/brand, space/x4
Don't#1A73E8 같은 색이나 13px 같은 간격을 직접 입력하지 않습니다.

개발 시작하기링크 복사

<head>에 두 줄을 넣고, 서비스 CSS는 그다음에 불러옵니다. 순서가 바뀌면 서비스 CSS가 YDS 변수를 덮어쓸 수 있습니다. 운영 중인 서비스는 버전을 고정한 주소를 사용합니다.

운영 중인 페이지에 적용하는 순서

  1. 위 두 줄을 <head>에, 서비스 CSS보다 앞에 넣습니다.
  2. 버튼과 입력 폼부터 YDS 컴포넌트로 바꿉니다. 배치는 그대로 둡니다.
  3. 색과 글자 크기를 YDS 변수로 바꿉니다.
  4. node yds-check.mjs 파일.html로 규칙을 점검합니다.
  5. 모바일과 다크 모드를 확인한 뒤 배포합니다.
