Get Started

YDS(YBM Design System)는 다양한 서비스를 일관된 경험으로 만들기 위한 디자인 시스템입니다.

구조

  1. YDS모든 서비스가 함께 쓰는 컴포넌트, 토큰, 규칙입니다.
  2. 브랜드색, 모서리, 글꼴처럼 모양만 바꾸는 값을 담은 파일입니다.
  3. 서비스YDS에 브랜드를 더해 실제 화면을 만듭니다.

AI로 빠르게 시작하기

아래처럼 자유롭게 적고 AI 도구에 붙여 넣으세요.

수강 신청 화면을 새로 만들려고 해. 강의를 고르고 신청까지 한 번에 할 수 있으면 좋겠어. YDS 템플릿에 비슷한 화면이 있으면 참고해서 YDS 컴포넌트로 만들어 줘. YDS 쓰는 법은 아래 파일에 있어. https://design.ybmnet.co.kr/yds/site/yds.txt

토큰 아끼는 팁

  • yds-full.txt 대신 yds.txt 주소를 넣으세요.
    https://design.ybmnet.co.kr/yds/site/yds.txt
  • 참고할 템플릿이나 컴포넌트 이름을 적어 주세요. AI가 찾느라 여러 파일을 읽지 않습니다.
  • 규칙 파일은 프로젝트에 두고 사용하세요.

Figma로 시작하기

YDS 라이브러리를 켜고 컴포넌트를 골라 화면을 만드세요.

  1. Figma의 Assets 패널에서 YDS 라이브러리를 켜고, 컴포넌트와 색, 간격, 글자는 YDS에 있는 값에서 골라 사용합니다.
    Assets에 YDS 라이브러리가 보이지 않으면 사내 워크 게시판에 권한을 요청하세요.

개발 시작하기

아래 코드를 <head>에 넣으면 YDS가 바로 적용됩니다.

파일

파일무엇인가요언제 쓰나요
yds.txtAI가 읽는 YDS 설명 파일AI에게 화면을 부탁할 때 요청 글에 이 주소를 함께 넣어 주세요.
Figma 라이브러리YDS 컴포넌트와 변수가 담긴 Figma 파일Figma에서 화면을 디자인할 때 라이브러리로 켜 주세요.
yds-full.txt컴포넌트 사용법과 규칙을 모은 파일 하나AI가 주소를 열지 못하면 yds.txt 대신 이 파일을 첨부해 주세요.
CLAUDE.mdyds.mdcAGENTS.md코딩 도구용 YDS 규칙 파일코딩 도구를 쓸 때 프로젝트 맨 위 폴더에 넣어 두세요. 요청할 때마다 yds.txt 주소를 넣지 않아도 됩니다.
yds-check.mjsYDS 규칙 검사 스크립트화면을 다 만든 뒤 한 번 실행해 보세요. YDS에 없는 색이나 클래스를 썼는지 찾아 줍니다.
