업데이트 소식과 변경 기록입니다.

소식요청

2026. 11. 26

  • 컴포넌트 Text Field, Select처럼 값을 넣는 컴포넌트의 테두리가 진해지고, 마우스를 올리면 더 진해집니다.
  • 컴포넌트 Table 머리 줄에 옅은 바탕이 깔리고 글자가 SemiBold로 바뀌었습니다.

2026. 11. 20

  • 규칙 AI 규칙이 마크업을 CSS 파일 대신 컴포넌트 문서에서 읽게 바뀌어 토큰이 크게 줄었습니다.

2026. 11. 19

  • 아이콘 UI 아이콘은 Lucide를 기본으로 권장합니다. 다른 세트도 쓸 수 있지만 한 화면에는 한 세트만 씁니다.

2026. 11. 18

  • 컴포넌트 Dialog, Bottom Sheet, Popover처럼 화면 위에 뜨는 컴포넌트가 닫힐 때도 부드럽게 사라집니다.

2026. 11. 17

  • 규칙 YDS 공식 주소가 사내 서버 https://design.ybmnet.co.kr/yds/ 로 바뀌었습니다.

2026. 11. 16

  • 템플릿 수강 설문 쓰기, 수강평 쓰기, 고사장 신청 (지도), AI 학습 대화 템플릿을 더했습니다.
  • 템플릿 AI 학습 리포트 템플릿을 더했습니다.
  • 토큰 글꼴과 CSS를 가볍게 해서 처음 받는 양이 3MB에서 수백 KB로 줄었습니다.
  • 컴포넌트 Avatar 상태 점이 모든 모양에서 오른쪽 아래 같은 자리에 놓입니다.

2026. 11. 15

  • 컴포넌트 Avatar 크기 42가 40으로 바뀌었습니다. 예전 42도 40으로 보입니다.

v1.2.0 2026. 11. 15

  • 템플릿 교재 홈, 교재 목록, 교재 음원, 교재 로드맵 템플릿을 더했습니다.
  • 컴포넌트 Image Frame에 책 표지 3:4, 포스터 2:3 비율을 더했습니다.
  • 컴포넌트 Radio Group을 가로로 놓을 수 있습니다.
  • 아이콘 volume-2, captions, headphones 아이콘을 더했습니다.
  • 템플릿 겹치거나 잘 쓰지 않는 템플릿 21개를 정리하고, 쇼핑 분류를 교재 분류로 바꿨습니다.

2026. 11. 14

  • 템플릿 영상 홈, 작품 상세, 영상 시청, 전체 화면 플레이어, 클래스 상세, 내 강의실 템플릿을 더했습니다.
  • 템플릿 관리자용 요청 목록, 요청 상세, 요청 등록 템플릿을 더했습니다.

2026. 11. 13

  • 컴포넌트 Accordion 제목을 콘텐츠 왼쪽 끝에 맞추는 data-inset="none"을 더했습니다.
  • 컴포넌트 Result Section 아이콘 크기를 data-size로 고를 수 있습니다.
  • 컴포넌트 Badge에 가장 큰 크기 xlarge를 더했습니다.
  • 컴포넌트 Result Section large의 제목과 아이콘이 커지고 여백이 줄었습니다.
  • 컴포넌트 Text Field, Select 같은 입력 칸 바탕이 투명에서 기본 바탕색으로 바뀌었습니다. underline 모양은 그대로입니다.

2026. 11. 12

  • 컴포넌트 Top Navigation 메뉴를 가운데에 둘 수 있습니다.
  • 컴포넌트 Text Link 끝에 화살표를 넣으면 밑줄이 빠집니다.
  • 컴포넌트 Carousel에 자동 넘김, 멈춤 버튼, 번호 버튼을 더했습니다.
  • 컴포넌트 Carousel 아래에 진행 막대와 버튼을 한 줄로 두는 모양을 더했습니다.
  • 컴포넌트 Carousel을 끝없이 넘길 수 있습니다.
  • 아이콘 play-solid, pause-solid 아이콘을 더했습니다.
  • 규칙 속성 이름을 data-tone, data-layout, data-size, data-orientation 네 가지로 통일했습니다. 예전 이름도 그대로 동작합니다.

2026. 11. 11

  • 컴포넌트 Tabs medium이 높이 48, 글자 16으로 커졌습니다.
  • 토큰 옅은 회색 칸이 반투명으로 바뀌어 회색 박스 안에서도 보입니다.
  • 컴포넌트 Dialog와 Bottom Sheet는 모달일 때만 뒤 화면 스크롤을 막습니다.
  • 컴포넌트 Field 안의 Code Input은 칸 묶음 너비에 맞춰집니다.
  • 컴포넌트 Table 맨 위와 맨 아래 선이 한 단계 짙어졌습니다.
  • 컴포넌트 회색 Toolbar 안 버튼은 ghost를 씁니다.

2026. 11. 10

  • 컴포넌트 새 컴포넌트 Segmented Text Input을 더했습니다. 카드번호처럼 나눠 입력하는 값에 씁니다.
  • 컴포넌트 새 컴포넌트 Date Field, Lightbox, Mega Menu, Command Palette를 더했습니다.
  • 규칙 컴포넌트 페이지마다 사용 지침을 더했습니다.
  • 컴포넌트 Table 위 선이 옅어지고 머리줄이 높이 40, 글자 14로 바뀌었습니다.
  • 컴포넌트 중립 Badge 바탕이 반투명으로 바뀌어 회색 박스 안에서도 보입니다.
  • 컴포넌트 Segmented Control medium 모서리를 같은 높이의 Button과 맞췄습니다.
  • 컴포넌트 Selection Bar가 Toolbar로 합쳐졌습니다.

2026. 11. 9

  • 브랜드 브랜드 구조를 더했습니다. YDS와 다른 색, 모서리, 글꼴만 파일 하나에 적으면 됩니다.
  • 컴포넌트 문장 안 Text Link는 주변 글자 크기를 따릅니다.
