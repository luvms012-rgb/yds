Updates

업데이트 소식과 변경 기록입니다.

소식요청사용 현황

2026. 11. 16

  • 템플릿 수강 설문 쓰기, 수강평 쓰기, 고사장 신청 (지도), AI 학습 대화 템플릿을 더했습니다. 수강 뒤 의견을 받는 화면, 지도로 고사장을 고르는 화면, AI와 대화하며 배우는 화면에 사용합니다.
  • 템플릿 AI 학습 리포트 템플릿을 더했습니다. AI와 학습을 마친 뒤 영역별 점수, 점수 변화, 고칠 문장을 보는 화면에 사용합니다.
  • 토큰 글꼴은 화면에 쓰인 글자 조각만 받고 CSS 는 한 파일로 묶어, 처음 받는 양이 약 3MB 에서 수백 KB 로 줄었습니다. 설치 코드는 그대로입니다.
  • 컴포넌트 Avatar 상태 점을 배지와 같은 오른쪽 아래 모서리에 맞췄습니다. 모든 모양에서 같은 자리에 놓입니다.

2026. 11. 15

  • 컴포넌트 Avatar 크기 42 를 40 으로 바꿨습니다. 모든 크기가 4의 배수가 됩니다. 예전 data-size="42" 도 40 으로 보입니다.

v1.2.0 2026. 11. 15

  • 템플릿 교재 템플릿에 교재 홈, 교재 목록, 교재 음원, 교재 로드맵을 더했습니다. 교재를 찾고 음원과 학습 자료로 이어지는 화면에 사용합니다.
  • 컴포넌트 Image Frame 에 책 표지 비율 data-ratio="3:4" 와 포스터 비율 data-ratio="2:3" 을 더했습니다.
  • 컴포넌트 Radio Group 에 가로 배치 data-orientation="horizontal" 을 더했습니다. 짧은 선택지 2~4개에 사용합니다.
  • 아이콘 소리 volume-2, 자막 captions, 음원 듣기 headphones 아이콘을 더했습니다.
  • 템플릿 잘 쓰이지 않거나 서로 겹치는 템플릿 21개를 정리했습니다. 도구와 문서 사이트 화면, 모양만 다른 갤러리와 설정 화면이 빠졌습니다. 쇼핑 분류는 교재 분류로 바꿨습니다.

2026. 11. 14

  • 템플릿 영상 서비스 템플릿에 영상 홈, 작품 상세, 영상 시청, 전체 화면 플레이어를, 학습 템플릿에 클래스 상세, 내 강의실을 더했습니다.
  • 템플릿 관리자 템플릿에 요청 목록, 요청 상세, 요청 등록을 더했습니다. 요청을 받아 승인, 진행, 완료로 처리하는 관리자 화면에 사용합니다.

2026. 11. 13

  • 컴포넌트 Accordion 에 data-inset="none" 을 더했습니다. 콘텐츠 칸 안에서 제목과 왼쪽 끝을 맞출 때 사용합니다.
  • 컴포넌트 Result Section 그림에 data-size 로 아이콘 크기(32, 40, 48, 64)를 고를 수 있게 했습니다.
  • 컴포넌트 Badge 에 글자 14 크기 xlarge 와 크기 변수(높이, 좌우 여백, 모서리, 글자, 아이콘)를 더했습니다.
  • 컴포넌트 Result Section large 의 제목을 t09 로 키우고 아이콘 48, 글자와 버튼 사이 여백을 줄였습니다.
  • 컴포넌트 Text Field Input, Text Field Textarea, Field Button, Select Trigger, Multi Select 의 바탕을 투명에서 bg/layer-default 로 바꿨습니다. underline 은 그대로 투명합니다.

2026. 11. 12

  • 컴포넌트 Top Navigation 에 메뉴를 막대 가운데에 두는 data-layout="center" 를 더했습니다.
  • 컴포넌트 Text Link 끝에 화살표 아이콘을 넣으면 밑줄 없이 표시됩니다. 전체 보기처럼 이동을 알리는 링크에 사용합니다.
  • 컴포넌트 Carousel 에 큰 배너용 자동 넘김, 멈춤 버튼, 전체 보기 번호 버튼을 더했습니다.
  • 컴포넌트 Carousel 에 항목 아래 진행 막대와 번호, 이동, 멈춤 버튼을 한 줄로 두는 모양(data-layout="bar")을 더했습니다.
  • 컴포넌트 Carousel 에 data-loop 를 붙이면 끝없이 넘깁니다. 첫 장과 마지막 장에서도 양옆 장이 보입니다.
  • 아이콘 채운 모양 아이콘 play-solid, pause-solid 를 더했습니다. Carousel 멈춤 버튼은 이 아이콘을 사용합니다.
  • 규칙 모양과 색을 고르는 속성 이름을 하나의 규칙으로 맞췄습니다. 색은 data-tone, 구조는 data-layout, 크기는 data-size, 방향은 data-orientation 으로 쓰고, 예전 이름도 계속 읽습니다.

2026. 11. 11

  • 컴포넌트 Tabs medium 크기를 높이 48, 글자 16으로 바꿨습니다. 크기마다 글자 크기도 함께 달라집니다.
  • 토큰 트랙, 빈 칸, 약한 버튼 같은 옅은 회색 칸을 반투명 회색으로 바꿨습니다. 회색 박스 안에 놓여도 보입니다.
  • 컴포넌트 Dialog와 Bottom Sheet는 모달로 열었을 때만 뒤 화면 스크롤을 막습니다.
  • 컴포넌트 Code Input을 Field에 넣으면 Field 너비가 칸 묶음에 맞춰집니다.
  • 컴포넌트 Table 맨 위와 맨 아래 선을 바깥 테두리 색으로 한 단계 짙게 바꿨습니다. 행 사이 선은 그대로 옅습니다.
  • 컴포넌트 회색 Toolbar(muted) 안 버튼은 ghost를 사용합니다. 바탕은 마우스를 올릴 때만 보입니다.

2026. 11. 10

  • 컴포넌트 새 컴포넌트 Segmented Text Input을 더했습니다. 주민등록번호, 카드번호처럼 일부를 가려야 하는 값을 구간마다 나눠 입력받습니다.
  • 컴포넌트 새 컴포넌트 4종을 더했습니다. Date Field, Lightbox, Mega Menu, Command Palette입니다.
  • 규칙 컴포넌트 사용 지침을 더했습니다. 버튼과 링크 문구, 입력 칸 라벨, 알림 고르는 법, 대비와 겹쳐 열지 않기 같은 기준을 각 컴포넌트 페이지에서 볼 수 있습니다.
  • 컴포넌트 Table 위 선을 옅은 선으로 바꾸고, 머리줄을 높이 40, 글자 14 Medium으로 바꿨습니다.
  • 컴포넌트 중립 Badge 바탕을 알파 색으로 바꿨습니다. 회색 박스 안에서도 배지가 보입니다.
  • 컴포넌트 Segmented Control medium의 모서리를 바깥 8, 안쪽 6으로 바꿨습니다. 같은 높이의 Button과 나란히 놓여도 모서리가 맞습니다.
  • 컴포넌트 Selection Bar를 Toolbar에 합쳤습니다. 떠 있는 막대와 선택 해제 버튼은 Toolbar에서 사용합니다.

2026. 11. 9

  • 브랜드 브랜드별 색, 모서리, 글꼴을 YDS와 다른 값만 적은 파일 하나로 입히는 브랜드 구조를 더했습니다.
  • 컴포넌트 문장 안(p, li)의 Text Link는 이제 size와 상관없이 주변 글자 크기를 따릅니다. 문장 속 링크 크기가 1 ~ 2px 달라질 수 있습니다.

자세한 변경 기록은 GitHub에 있습니다.
