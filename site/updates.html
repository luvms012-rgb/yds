Updates

yds 업데이트 소식과 변경 기록입니다.

2026. 11. 9

바뀐 것

  • 사이트 Get Started의 브랜드 만들기를 서비스 시작하기에 합쳐, 요청 글 하나로 브랜드와 서비스를 함께 시작하도록 바꿨습니다.
  • 사이트 새 소식이 있으면 상단 Updates 메뉴에 점으로 표시합니다.
  • 사이트 Get Started를 yds의 의도가 먼저 보이도록 다시 쓰고, Figma로 시작하는 방법을 더했습니다.
  • 사이트 브랜드에서 바꿀 수 있는 값을 색, 모서리, 글꼴로 정리했습니다.
  • 사이트 AI용 yds-full.txt에서 예시, 규격, 구조를 빼 크기를 3분의 1로 줄였습니다. 이 내용은 각 페이지의 Markdown에 있습니다.
  • 사이트 컴포넌트 구조 그림의 화살표가 실제 글자와 아이콘을 가리키도록 고치고, 빠져 있던 부품을 더했습니다.
  • 사이트 컴포넌트, Foundations, 템플릿 설명 문구를 다듬었습니다.
  • 사이트 템플릿 분류 탭을 가나다 순으로 바꿨습니다.
  • 사이트 Get Started를 운영 중인 사이트, 새 서비스, 화면 시안 세 가지 시작 방법으로 줄이고, 칸마다 AI 요청 글 하나와 HTML을 두었습니다.
  • 사이트 AI 규칙에 yds 원본 파일은 고치지 않고 서비스 CSS에서 덮어쓴다는 규칙을 더했습니다.
  • 사이트 화면 시안 요청 글에 파일 첨부 대신 yds-full.txt 주소를 넣었습니다.
  • 사이트 Get Started를 yds와 브랜드, 서비스의 관계에 맞춰 브랜드 만들기부터 서비스 시작까지 다시 구성했습니다.
  • 사이트 AI가 읽는 문서 이름을 yds.txt와 yds-full.txt로 바꿨습니다.
  • DS 브랜드 버튼 위 글자색을 바꾸면 Switch 손잡이도 함께 바뀝니다.
  • DS Card 제목에만 있던 자간을 빼서 다른 글자와 맞췄습니다.
  • 사이트 yds에 없는 아이콘은 yds 파일이 아니라 내 서비스 CSS에 넣도록 안내를 바꾸고, 규칙 검사도 그 아이콘을 인식합니다.
  • 사이트 문서 페이지 아래와 푸터에 yds 담당자에게 의견을 보내는 링크를 더했습니다.
  • DS Side Panel 닫기 아이콘을 내용 오른쪽 끝과 제목 줄 가운데에 맞췄습니다.
  • DS 브랜드별 색, 모서리, 글꼴을 yds와 다른 값만 적은 파일 하나로 입히는 브랜드 구조를 더했습니다.

자세한 변경 기록은 GitHub에 있습니다.
