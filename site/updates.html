Updates

업데이트 소식과 변경 기록입니다.

소식요청

2026. 11. 13

  • DS Accordion 에 data-inset="none" 을 더했습니다. 콘텐츠 칸 안에서 제목과 왼쪽 끝을 맞출 때 사용합니다.
  • DS Result Section 그림에 data-size 로 아이콘 크기(32, 40, 48, 64)를 고를 수 있게 했습니다.
  • DS Badge 에 글자 14 크기 xlarge 와 크기 변수(높이, 좌우 여백, 모서리, 글자, 아이콘)를 더했습니다.
  • DS Result Section large 의 제목을 t09 로 키우고 아이콘 48, 글자와 버튼 사이 여백을 줄였습니다.
  • DS Text Field Input, Text Field Textarea, Field Button, Select Trigger, Multi Select 의 바탕을 투명에서 bg/layer-default 로 바꿨습니다. underline 은 그대로 투명합니다.

2026. 11. 12

  • DS Top Navigation 에 메뉴를 막대 가운데에 두는 data-layout="center" 를 더했습니다.
  • DS Text Link 끝에 화살표 아이콘을 넣으면 밑줄 없이 표시됩니다. 전체 보기처럼 이동을 알리는 링크에 사용합니다.
  • DS Carousel 에 큰 배너용 자동 넘김, 멈춤 버튼, 전체 보기 번호 버튼을 더했습니다.
  • DS Carousel 에 항목 아래 진행 막대와 번호, 이동, 멈춤 버튼을 한 줄로 두는 모양(data-layout="bar")을 더했습니다.
  • DS Carousel 에 data-loop 를 붙이면 끝없이 넘깁니다. 첫 장과 마지막 장에서도 양옆 장이 보입니다.
  • DS 채운 모양 아이콘 play-solid, pause-solid 를 더했습니다. Carousel 멈춤 버튼은 이 아이콘을 사용합니다.
  • DS 모양과 색을 고르는 속성 이름을 하나의 규칙으로 맞췄습니다. 색은 data-tone, 구조는 data-layout, 크기는 data-size, 방향은 data-orientation 으로 쓰고, 예전 이름도 계속 읽습니다.

2026. 11. 11

  • DS Tabs medium 크기를 높이 48, 글자 16으로 바꿨습니다. 크기마다 글자 크기도 함께 달라집니다.
  • DS 트랙, 빈 칸, 약한 버튼 같은 옅은 회색 칸을 반투명 회색으로 바꿨습니다. 회색 박스 안에 놓여도 보입니다.
  • DS Dialog와 Bottom Sheet는 모달로 열었을 때만 뒤 화면 스크롤을 막습니다.
  • DS Code Input을 Field에 넣으면 Field 너비가 칸 묶음에 맞춰집니다.
  • DS Table 맨 위와 맨 아래 선을 바깥 테두리 색으로 한 단계 짙게 바꿨습니다. 행 사이 선은 그대로 옅습니다.
  • DS 회색 Toolbar(muted) 안 버튼은 ghost를 사용합니다. 바탕은 마우스를 올릴 때만 보입니다.

2026. 11. 10

  • DS 새 컴포넌트 Segmented Text Input을 더했습니다. 주민등록번호, 카드번호처럼 일부를 가려야 하는 값을 구간마다 나눠 입력받습니다.
  • DS 새 컴포넌트 4종을 더했습니다. Date Field, Lightbox, Mega Menu, Command Palette입니다.
  • DS 컴포넌트 사용 지침을 더했습니다. 버튼과 링크 문구, 입력 칸 라벨, 알림 고르는 법, 대비와 겹쳐 열지 않기 같은 기준을 각 컴포넌트 페이지에서 볼 수 있습니다.
  • DS Table 위 선을 옅은 선으로 바꾸고, 머리줄을 높이 40, 글자 14 Medium으로 바꿨습니다.
  • DS 중립 Badge 바탕을 알파 색으로 바꿨습니다. 회색 박스 안에서도 배지가 보입니다.
  • DS Segmented Control medium의 모서리를 바깥 8, 안쪽 6으로 바꿨습니다. 같은 높이의 Button과 나란히 놓여도 모서리가 맞습니다.
  • DS Selection Bar를 Toolbar에 합쳤습니다. 떠 있는 막대와 선택 해제 버튼은 Toolbar에서 사용합니다.

2026. 11. 9

  • DS 브랜드별 색, 모서리, 글꼴을 YDS와 다른 값만 적은 파일 하나로 입히는 브랜드 구조를 더했습니다.
  • DS 문장 안(p, li)의 Text Link는 이제 size와 상관없이 주변 글자 크기를 따릅니다. 문장 속 링크 크기가 1 ~ 2px 달라질 수 있습니다.

자세한 변경 기록은 GitHub에 있습니다.
