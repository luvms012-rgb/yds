# YDS

> YDS는 디자이너, 개발자, AI가 같은 이름으로 같은 화면을 만들게 돕는 디자인 시스템입니다. HTML에 .ds-* 클래스를 붙이고 --ds-* 토큰으로 색, 간격, 글자를 맞춥니다. 이 파일은 AI 도구가 읽도록 문서 목록을 모은 것입니다.

- 버전: 1.1.0 (버전 고정 주소 https://cdn.jsdelivr.net/gh/luvms012-rgb/yds@v1.1.0/dist/ybm-ds.css)
- CSS: https://luvms012-rgb.github.io/yds/dist/ybm-ds.css
- JS: https://luvms012-rgb.github.io/yds/dist/ybm-ds.js
- 사용법과 규칙 모음: https://luvms012-rgb.github.io/yds/site/yds-full.txt (예시, 규격, 구조는 각 쪽 .md에 있다)
- 규칙 파일: https://luvms012-rgb.github.io/yds/site/ai/AGENTS.md
- 아이콘 목록: https://luvms012-rgb.github.io/yds/site/ai/icons.json
- 검사 스크립트: https://luvms012-rgb.github.io/yds/site/ai/yds-check.mjs
- 컴포넌트 목록: https://luvms012-rgb.github.io/yds/components.json, 마크업: https://raw.githubusercontent.com/luvms012-rgb/yds/main/dist/components.css
- 토큰: https://raw.githubusercontent.com/luvms012-rgb/yds/main/dist/tokens.css (표준 형식 https://luvms012-rgb.github.io/yds/tokens/design-tokens.json, JS https://luvms012-rgb.github.io/yds/tokens/tokens.js, Tailwind https://luvms012-rgb.github.io/yds/tokens/tailwind.preset.js)

## 지킬 것

- 설치: <head>에 CSS와 JS 두 줄을 넣는다. 서비스 CSS는 그다음에 불러온다. 운영 서비스는 버전을 고정한 주소(https://cdn.jsdelivr.net/gh/luvms012-rgb/yds@v1.1.0/dist/ybm-ds.css, ybm-ds.js)를 쓴다.
- 규칙 파일: 설치할 때 규칙 파일(https://luvms012-rgb.github.io/yds/site/ai/AGENTS.md)을 프로젝트 맨 위 폴더에 받아 둔다. Claude는 CLAUDE.md, Cursor는 .cursor/rules/yds.mdc 이름으로 둔다.
- 컴포넌트: 목록(https://luvms012-rgb.github.io/yds/components.json)에 있는 것만 쓰고, 마크업은 컴포넌트 CSS(https://raw.githubusercontent.com/luvms012-rgb/yds/main/dist/components.css)의 컴포넌트별 머리 주석 그대로 쓴다.
- 링크: 문장 안의 Text Link 는 주변 글자 크기를 그대로 따른다. 크기를 따로 지정하지 않는다.
- 아이콘: 목록(https://luvms012-rgb.github.io/yds/site/ai/icons.json)에 있는 이름만 쓴다. 꾸밈 아이콘에는 aria-hidden="true", 아이콘만 있는 버튼에는 aria-label을 붙인다.
- 색, 간격, 글자 크기, 모서리, 그림자는 --ds-* 토큰만 쓴다. hex, rgb를 직접 쓰지 않는다.
- 원본: YDS 파일(ybm-ds.css, ybm-ds.js 등)은 담당자만 고친다. 가져다 쓰는 쪽은 원본을 고치거나 복사해 고치지 않고, 바꿀 것은 서비스 CSS에서 덮어쓴다. YDS 자체를 바꿔야 하면 담당자에게 요청한다.
- 모양을 바꿀 때는 컴포넌트 변수(--ds-[컴포넌트]-*)만 덮어쓴다. 새 ds- 클래스나 !important를 만들지 않는다.
- 브랜드: 브랜드 파일(https://luvms012-rgb.github.io/yds/dist/brands/브랜드이름.css)을 YDS CSS 다음, 서비스 CSS 앞에 불러오고 <html>에 data-ds-brand="브랜드이름"을 단다. 브랜드 값을 서비스 CSS에 따로 적지 않는다.
- 새 브랜드: 브랜드 파일(JSON)에는 YDS와 다른 값만 적는다. 쓸 수 있는 값은 name(필수), color(대표색, 600 단계) 또는 palette(light, dark 각 100~1000), shapeScale(모서리 배수 0~2), font(글꼴)뿐이다. 브랜드 버튼 글자 대비는 4.5 이상이어야 한다. 파일은 담당자가 등록한다. 등록 전까지만 서비스 CSS의 :root에서 --ds-color-palette-brand-100 ~ 1000을 임시로 덮어쓴다.
- 브랜드 값을 받지 못했으면 시작 전에 브랜드 이름과 대표색을 묻는다. 모서리와 글꼴은 말이 없으면 YDS 값을 쓴다. 브랜드 파일이 없으면 YDS와 다른 값만 담아 먼저 만들고, 글자 대비 수치가 부족하면 고칠 색을 제안한다.
- 시작: 무엇을 만들지 듣지 못했으면 먼저 묻는다. 다 만들면 고친 곳을 알려 준다.
- 화면: 모바일 먼저 만들고 768px, 1280px에서 배치를 바꾼다. 비슷한 화면이 Templates에 있으면 그 HTML에서 시작한다.
- 글자: 한국어. 제목 Bold, 항목 제목 SemiBold, 본문 Regular, 본문은 word-break: keep-all.
- 점검: 끝내기 전에 검사 스크립트(https://luvms012-rgb.github.io/yds/site/ai/yds-check.mjs)를 받아 node로 돌리고, 나온 문제를 모두 고친다.

## 운영 중인 사이트에 옮길 때

- 한 번에 다 바꾸지 않는다. 살펴보기, YDS 넣기, 브랜드, 화면 하나씩, 점검 순서로 간다.
- 원래 되던 기능은 그대로 동작해야 한다. 애매한 부분은 혼자 정하지 말고 물어본다.
- DS는 @layer 안에 있어 기존 CSS가 늘 이긴다. 그래서 DS를 넣기만 해서는 지금 화면이 바뀌지 않는다. 기존 규칙이 DS 컴포넌트를 덮으면 그 화면의 기존 규칙만 걷어 낸다.
- 서버 코드(PHP, JSP 등)의 로직은 바꾸지 않는다. 스크립트와 서버가 쓰는 class, id, name 속성은 그대로 두고, 필요하면 DS 클래스를 함께 붙인다.
- 기존 CSS의 hex 색은 가까운 --ds-color-* 역할 토큰으로 바꾸고, 바꾼 짝은 목록으로 남긴다.
- 화면을 바꿀 때마다 바꾸기 전후 화면을 비교해 보여 주고 확인을 받는다.

## Foundations

- [Color](https://luvms012-rgb.github.io/yds/site/foundations/color.md): 색은 정보의 위계와 상태, 브랜드를 구분해 전달합니다.
- [Typography](https://luvms012-rgb.github.io/yds/site/foundations/typography.md): 타이포그래피는 정보의 위계를 구분하고 글을 읽기 쉽게 만듭니다.
- [Spacing](https://luvms012-rgb.github.io/yds/site/foundations/spacing.md): 간격은 요소 사이의 거리로 관계와 묶음을 나타냅니다.
- [Breakpoint](https://luvms012-rgb.github.io/yds/site/foundations/breakpoint.md): 화면 너비에 따라 레이아웃이 바뀌는 지점입니다.
- [Radius](https://luvms012-rgb.github.io/yds/site/foundations/shape.md): 모서리는 요소의 둥글기를 정해 일관된 인상을 만듭니다.
- [Elevation](https://luvms012-rgb.github.io/yds/site/foundations/elevation.md): 그림자와 겹침 순서는 요소의 높낮이와 앞뒤 관계를 나타냅니다.
- [Motion](https://luvms012-rgb.github.io/yds/site/foundations/motion.md): 움직임은 화면의 변화를 자연스럽게 이어 줍니다.
- [Color Roles](https://luvms012-rgb.github.io/yds/site/foundations/color-roles.md): 역할 색의 규칙과 전체 토큰
- [Color Palette](https://luvms012-rgb.github.io/yds/site/foundations/color-palette.md): 팔레트 색의 단계와 전체 토큰
- [Iconography](https://luvms012-rgb.github.io/yds/site/foundations/icons.md)
- [Icon Library](https://luvms012-rgb.github.io/yds/site/foundations/icons-library.md): 아이콘을 찾아 클래스와 SVG를 복사합니다

- [Select Content](https://luvms012-rgb.github.io/yds/site/components/select-content-item.md): Select를 눌렀을 때 펼쳐지는 선택지 목록입니다.

- [Radio Group](https://luvms012-rgb.github.io/yds/site/components/radio-group.md): 여러 선택지 중 하나만 선택할 때 사용하는 컴포넌트입니다.
