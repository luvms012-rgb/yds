## 주의

- Windows 에서 `node sync.mjs deploy` 의 검사가 "7 빌드 경고, site/build.mjs 실패" 로 멈추면 대개 파일 잠금이다. `node site/build.mjs` 를 한 번 돌리고 배포를 다시 하면 된다.
- 문자열 안 `<` 같은 역슬래시는 Edit 도구가 풀어 버린다. 그런 줄은 node 스크립트 파일로 고친다.
- 숨은 브라우저 패널에서는 타이머와 IntersectionObserver 가 멈춘다. 움직임 확인은 헤드리스 Chrome(`--user-data-dir` 를 따로 줘야 저장된다).
- 템플릿은 생성기(`site/templates/gen/*.mjs`)를 고친다. `pages/*.html` 손 수정은 다음 빌드에서 되돌아간다.
